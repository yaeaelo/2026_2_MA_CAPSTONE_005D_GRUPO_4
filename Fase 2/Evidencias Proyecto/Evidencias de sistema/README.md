# Código fuente oficial

Esta carpeta conserva snapshots verificables del producto. El vigente está en `BeatsCloud-ee981a7/`: copia exacta de los 297 archivos rastreados en `felipe-urtubia/BeatsCloud` en `ee981a750904b4263b20be2f91e3568c0e1699ea`, con 297 entradas SHA-256 más `SOURCE_COMMIT.txt` y `SHA256SUMS` (299 archivos en total). `BeatsCloud-12a3ea0/`, `BeatsCloud-e48174f/`, `BeatsCloud-96918f4/` y `BeatsCloud-5021ee8/` se conservan como cortes históricos.

El snapshot `96918f4` contiene el corte de 294 archivos; los snapshots `12a3ea0` y `e48174f` mantienen sus árboles originales. `ee981a7` incorpora los rewrites Vercel, protección de `.env.qa`, Anymail/Resend y backend Gmail API. La extracción actual se generó desde objetos Git e incluye todos los archivos rastreados, incluso los excluidos por `git archive`; se verificó contenido byte por byte.

Se incluyen `.env.example` y `frontend/client/.env.example`, idénticos a la fuente. No se incluyen `.env`, `.env.qa`, bases de datos locales, `node_modules`, entornos virtuales, `dist`, medios generados localmente, archivos ZIP ni contenedores `agregar.html`. No se copia metadata `.git`. El snapshot contiene el árbol rastreado del producto, no una segunda implementación.

Las 372 pruebas Django, `manage.py check`, migraciones, `build.sh` y smoke HTTP se repitieron en `4569613b29e7023161149ca5e7d5fddabf6437db`. El snapshot vigente `ee981a7` fija el árbol final posterior a esas pruebas. Vercel requiere `frontend/client` como Root Directory; no se verificó el panel ni despliegue externo. Webpay sandbox, Gmail/Resend, R2, SMTP y los cuatro casos manuales siguen pendientes.
