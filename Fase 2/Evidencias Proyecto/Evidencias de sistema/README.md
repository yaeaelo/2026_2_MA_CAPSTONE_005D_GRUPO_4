# Código fuente oficial

Esta carpeta conserva dos snapshots verificables del producto. El snapshot vigente está en `BeatsCloud-96918f4/`: copia exacta de los 294 archivos rastreados en `felipe-urtubia/BeatsCloud` en el commit `96918f43f147d46d5ae65746c988979c36854637`, con 294 entradas de SHA-256; `SOURCE_COMMIT.txt` y `SHA256SUMS` son los dos metadatos añadidos, por lo que el directorio contiene 296 archivos en total. El snapshot anterior `BeatsCloud-5021ee8/` se mantiene intacto como corte histórico de 292 archivos.

La diferencia del snapshot actual respecto del anterior es de dos documentos nuevos del producto: `contribuciones_interrepositorios.md` y `validacion_qa_cierre_2026-11-19.md`; los cambios restantes entre commits son documentación y tooling de QA, no funcionalidades de producto. El inventario de 252 archivos de aplicación/configuración/recursos, más README raíz, `REGISTRO_CAMBIOS_BEATSCLOUD.md`, 38 documentos `docs/` y dos elementos de configuración/despliegue suma los 294 archivos versionados del nuevo snapshot.

Se incluyen `.env.example` y `frontend/client/.env.example`, byte por byte idénticos a la fuente. No se incluyen `.env`, `.env.qa`, bases de datos locales, `node_modules`, entornos virtuales, `dist`, medios generados localmente, archivos ZIP ni contenedores `agregar.html`. No se copia metadata `.git`. El snapshot es contenido versionado, no una segunda implementación.

El cierre QA se ejecutó localmente con una base QA aislada y está registrado en [evidencia QA 19-11](../Evidencias%20de%20documentación/validacion_qa_cierre_2026-11-19.md). Build, estáticos y migraciones se verificaron en esa base local; no se afirma despliegue Render. Integraciones reales de Webpay, R2 y SMTP, pruebas manuales de navegador y E2E de compra/descarga siguen pendientes.
