## Lectura y límites

- Sprint 1: el acta original se conserva en `../../Evidencias Proyecto/Evidencias de documentación/acta_sprint_1.md`. La ficha extrae sus afirmaciones; no reemplaza ni corrige el original.
- Sprint 2 y 3: el archivo fuente principal es la exportación de WhatsApp `~/Downloads/Capstone (1)/chat.txt` (exportada el 18-11-2026). El chat acredita mensajes y coordinación, no que cada asunto se haya tratado en una retrospectiva. Las conclusiones derivadas están etiquetadas.
- La evidencia técnica histórica de Sprint 2 en `VERIFICACION_SPRINT_2.md` respalda el estado reportado de pruebas, no una Review ni una retrospectiva.
- Las fechas de comienzo/cierre, puntos comprometidos, responsables formales y estados vigentes del tablero deben contrastarse con Jira. El equipo informó tres retrospectivas; no se agrega una cuarta.
- Los DOCX son copias de lectura para revisión académica; los Markdown son las fuentes editables. No se presentan como formularios institucionales aprobados.
